User Guide
==========

Everything you need to submit and manage work on a Spur cluster. If you already
know Slurm, your commands and job scripts work unchanged — see
:doc:`slurm-compatibility` and :doc:`/migration-from-slurm`.

This guide covers the :doc:`architecture`, :doc:`submitting-jobs`,
:doc:`interactive` jobs, :doc:`monitoring-jobs`, :doc:`running-containers`, and
:doc:`slurm-compatibility`.
